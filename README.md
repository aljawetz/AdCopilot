## Course

This is a project-based applied learning course. The point is to ship a working product, not a slide deck.

Teams of 4-6 students pick a real industry or social problem, then build a complete software system around it: realistic inputs, processing (including AI where it actually helps), and output that a user would value. A smaller system that works end to end beats an ambitious one that never quite runs.

The Integrated Innovation Institute lists 49797 as one of the full-semester applied learning options (alongside Integrated Innovation for Large-Scale Problems and Start-Up Creation in Practice).

## What the course expects

From the Sprint 1 brief and the final defense:

- Identify a problem that matters, is evidenced, and is scoped for one semester.
- Understand users, customers, and beneficiaries (they are not always the same person).
- Know how the problem is handled today, and why the proposed system is better.
- Define technical *and* impact metrics.
- Do not chase novelty for its own sake. The class frames success as: meaningful problem × user need × technical feasibility × execution × measurable impact.
- Final bar: a functioning Must Have workflow, evidence (technical results, baselines, stakeholder validation), a live defense, and documentation.
